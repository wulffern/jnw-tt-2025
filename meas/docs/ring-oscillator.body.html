03 / Start-up

One oscillation, and one state we cannot measure

The ring reaches its oscillation only from a particular start-up sequence. The other sequence leaves it in a state whose output is faster than this analyser can follow — which is not the same as a second oscillation mode, and is not claimed to be one.

Why a second mode is unlikely

— is prime. A multi-wave pattern can only split a ring into gcd(k, N) independent sub-loops, and with N prime that is 1 for every k — the ring cannot decompose, it has to oscillate as a single loop. That does not forbid one loop carrying several waves, but it removes the usual mechanism for a second stable state, and the measured — is exactly the fundamental a ring this long should give.

What the other state is not

Sampling it at 500, 250 and 125 MS/s gives —. No single frequency explains those three. Solving for one leaves a — residual, while the same solver recovers a synthetic 437.3 MHz tone exactly — so the fault is in the data, not the method. Edge extraction has broken down on something too fast to track, and the readings are sampling artefacts rather than a frequency. Calling it a "mode" would be reading structure into noise.

An earlier version of this deck called these two modes of the ring and quoted a frequency for the second. That was wrong on both counts: the primality argument above says a prime-length ring should not have a second state of that kind, and the alias test says our number for it was never a measurement in the first place. Everything that follows is from the oscillation, verified before each capture.

04 / Phase noise

The measurement, and the reason to believe it

Single-sideband phase noise from the time-interval error — the running sum of period deviations — sampled once per cycle. The instrument's own quantisation is coarse here (4 ns on a 339 ns period), so the curve is only worth anything if it survives changing the timebase. It does.

05 / Averaging

How far averaging gets you

The Allan deviation of the same record. Single periods are dominated by the analyser's 4 ns sample quantum, but averaging beats that down, so the long-τ end describes the ring rather than the instrument.

06 / What is not here

The limits of this measurement

Three things a reader might reasonably expect, and why they are absent rather than estimated.

Per-inverter delay

Dividing the period by 2N would give ~44 ps, and that number is only right if this oscillation is the fundamental of the full —-stage loop. That is very likely — the stage count is prime, so the ring cannot split into sub-loops — but "very likely" is an argument, not a measurement, and the second start-up state is still unexplained. Left out.

Cycle-to-cycle jitter

Not resolved. A 4 ns timebase on a 339 ns period means the analyser's own quantisation accounts for about 95 % of the period spread. An upper bound is all this instrument supports, and an upper bound is not a jitter figure.

Temperature coefficient

A ring's delay is strongly temperature-dependent and this would have been the most useful number of all. It needs a climate chamber, which was not available. Self-heating alone shifts it about 230 ppm over the first seconds, which sets the scale.

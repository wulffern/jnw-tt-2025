03 / Two modes

Which mode it starts in is decided by how you start it

The ring settles into one of two states, and for a while that looked like a coin toss — measurements that would not reproduce. It is not random. The start-up sequence selects it, deterministically.

Why it matters

Every figure in this deck is from the slow mode, reached by the sequence above and verified before each capture rather than assumed. An earlier attempt at these numbers was thrown away because it had silently been taken in the fast mode.

What the fast mode is

Unknown, and deliberately left so. It aliases to a different frequency at every sample rate we have — — — which places it above 125 MHz and beyond this instrument. A ring can carry several waves at once, so a harmonic relation is plausible, but undersampling a square wave does not alias cleanly enough to test it. Reporting a number here would be inventing one.

04 / Phase noise

The measurement, and the reason to believe it

Single-sideband phase noise from the time-interval error — the running sum of period deviations — sampled once per cycle. The instrument's own quantisation is coarse here (4 ns on a 339 ns period), so the curve is only worth anything if it survives changing the timebase. It does.

05 / Averaging

How far averaging gets you

The Allan deviation of the same record. Single periods are dominated by the analyser's 4 ns sample quantum, but averaging beats that down, so the long-τ end describes the ring rather than the instrument.

06 / What is not here

The limits of this measurement

Three things a reader might reasonably expect, and why they are absent rather than estimated.

Per-inverter delay

Dividing the period by 2N would give ~44 ps, and that number is only right if the slow mode is the fundamental of the full —-stage loop. With a second mode present and unidentified, that is an assumption rather than a measurement, so it is left out.

Cycle-to-cycle jitter

Not resolved. A 4 ns timebase on a 339 ns period means the analyser's own quantisation accounts for about 95 % of the period spread. An upper bound is all this instrument supports, and an upper bound is not a jitter figure.

Temperature coefficient

A ring's delay is strongly temperature-dependent and this would have been the most useful number of all. It needs a climate chamber, which was not available. Self-heating alone shifts it about 230 ppm over the first seconds, which sets the scale.
